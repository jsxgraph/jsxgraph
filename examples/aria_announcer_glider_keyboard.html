Gliders on a function graph, a parametric curve and a circle (keyboard control)

Focus a glider (Tab) and move it with the arrow keys. For gliders, all four arrow keys move the point along its curve: right/up forward, left/down backward. The step is the attribute keyboardStep, given in units of the curve's parameter:

  • function graph: x units (keyboardStep: 0.25),
  • parametric curve: units of t (keyboardStep: 0.2),
  • circle: fraction of a full turn (keyboardStep: 0.05, i.e. 18°).

The new position is announced once the movement has settled. Serve the repository over http (e.g. npx http-server), as ES modules do not load from file://.
